Welcome to Computer Science Portal

A computer is an electronic device that manipulates information, or data. It has the ability to store, retrieve, and process data. You may already know that you can use a computer to type documents, send email, play games, and browse the Web.

Core Components of a Computer

  • Hardware: The physical parts of a computer that you can see and touch (CPU, RAM, Motherboard, Keyboard, Mouse).
  • Software: A set of instructions or programs that tells the hardware what to do (Web browsers, Games, Operating Systems).

Input vs Output Devices

Input Devices: Used to send data to the computer (e.g., Keyboard, Mouse, Scanner, Microphone).

Output Devices: Used to show or send data out of the computer (e.g., Monitor, Printer, Speakers, Headphones).
