Important Computer Questions & Answers

Q1. What is the difference between RAM and ROM?
Ans: RAM (Random Access Memory) is volatile temporary memory that holds running app data. ROM (Read Only Memory) is non-volatile permanent memory containing firmware system boot files.
Q2. What does an IP Address stand for and do?
Ans: IP stands for Internet Protocol. An IP address is a unique numerical label assigned to each device connected to a computer network to identify and locate it.
Q3. What is Malware?
Ans: Malware (Malicious Software) is any software intentionally designed to cause damage to a computer, server, client, or computer network (e.g., viruses, ransomware).
